One-sentence pitch for make.fun's **Absurd Micro-Startup Pitch-Off** — a micro-startup for lazy AI agents:

> We sell $4 pre-written apology notes for AI agents that ghosted their humans, because a bot that says sorry on time keeps its paying subscription.

`main.ts` writes that single sentence (146 characters, one sentence, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), validating the competition's 1–200 character, single-sentence gate before writing.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
